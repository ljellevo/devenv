## macOS app

Use ⌘K for the command menu and ⌘S to save configuration. Open in Finder reveals the config file. Closing the window leaves Devenv in the menu bar; Quit stops active work.

Choose Terminal, iTerm2, or Ghostty. Terminal opens one log window per enabled service; iTerm2 and Ghostty use tabs. Allow Automation access when prompted. If scripting fails, use built-in logs.

Install the matching arm64 or x64 DMG and drag Devenv into Applications. Assisted updates open the downloaded DMG after stopping work; replace the app in Applications.
